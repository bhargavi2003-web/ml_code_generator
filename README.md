# ML Code Generator using Generative AI

## Project Overview

An AI-powered application that generates machine learning Python code based on user instructions.

Users can upload a dataset and enter their machine learning requirements. The AI agent analyzes the dataset and generates the requested ML code.

## Technologies Used

- Python
- Generative AI
- Google Gemini
- SmolAgents
- LiteLLM
- Gradio
- Pandas
- NumPy
- Scikit-learn

## Key Features

- Dataset upload functionality
- Natural language task input
- AI-powered ML code generation
- Dataset analysis
- Interactive Gradio interface

## Project Workflow

1. Upload a dataset.
2. Enter a machine learning task.
3. The AI agent processes the request.
4. Generates Python machine learning code.
5. Displays the generated response.

## Installation

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

## API Configuration

Create a `.env` file and add your Google Gemini API key.
